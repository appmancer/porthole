PORTHOLE

Sprite & Tile Index — Graphics Designer Brief

PORTHOLE is a 2D platformer demake of Valve’s Portal, running on the BBC Master 128 — an 8-bit British home computer from 1986. This document lists every sprite and tile in the game with its function, layer assignment, and current artwork. All images in this document are rendered at the correct 2:1 pixel aspect ratio as they appear on real hardware.

Split-nibble palette rule. In MODE 2 the 16 palette slots are divided: slots 0–7 are reserved for background tiles, slots 8–15 for foreground sprites. Sprites are composited onto tiles by a fast OR operation — no masking pass. A sprite's “transparent” pixel must be drawn as colour index 8 (mapped to black), which the OR leaves unchanged. Design tiles and sprites using the sub-palettes below and do not mix them.

Technical Constraints

Pixel aspect ratio: 2 : 1 (wide). BBC Micro MODE 2 pixels are twice as wide as they are tall on real hardware. The sprite images in this document are already rendered at 2:1 — what you see here is how sprites look on screen. Design your art to look correct at this ratio; do not draw in a square-pixel tool and submit without checking aspect.

The pixel grid for each sprite category:

  • Character sprites (Chell, objects): 12 logical pixels wide × 24–32 pixels tall. The data slot is 16 px wide; the rightmost 4 px are a shift-expansion zone auto-generated by the build tools — keep visible content within the first 12 px.
  • Portal sprites: 8 px wide (vertical wall portals) or 16 px wide (horizontal / front-facing).
  • Tiles: 8 logical pixels wide × 16 pixels tall (one character cell wide, two cells tall).
  • Subpixel pre-shifting: the engine pre-generates four sub-character-cell variants (x0–x3) from each base sprite by shifting 0–3 px right. These are synthesised automatically; you supply only the base frame.

Delivery format: PNG with a transparent background, using only the exact hex colours listed above. Alternatively, the project's CSV pixel-grid format (0/1/2/3 per pixel, . for transparent) — ask the developer for a template.
